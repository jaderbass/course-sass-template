# Sass (SCSS) – CSS effizient entwickeln

Dieses Repository enthält Unterrichtsmaterialien, Codebeispiele und Übungen zum **CSS-Präprozessor Sass** in der SCSS-Syntax.

Die Beispiele vermitteln schrittweise, wie sich Stylesheets durch Variablen, Verschachtelungen, wiederverwendbare Regeln und modulare Strukturen effizienter entwickeln und verwalten lassen.

## Kursinhalte

- Einführung in Sass und die Unterschiede zwischen CSS und SCSS
- Einrichtung und Verwendung des Live Sass Compilers
- Variablen und Datentypen
- Verschachtelung von CSS-Regeln (Nesting)
- Maps und Listen
- Mixins mit `@mixin` und `@include`
- Kontrollstrukturen mit `@if`, `@else` und `@each`
- Schleifen mit `@for` und `@while`
- Interpolation mit `#{}`
- Eigene Funktionen mit `@function`
- Verwendung der integrierten Sass-Module, beispielsweise `sass:color` und `sass:math`
- Aufteilung von Stylesheets in Partials und Module
- Modularisierung mit `@use` und `@forward`
- Zusammenspiel von Sass-Variablen und CSS Custom Properties

## Entwicklungsumgebung

Die Beispiele sind für die Arbeit mit **Visual Studio Code** vorgesehen.

Für die automatische Kompilierung der SCSS-Dateien wird die Erweiterung **Live Sass Compiler von Glenn Marks** verwendet.

Der Watcher wird über **Watch Sass** in der Statusleiste von VS Code gestartet. Änderungen an den SCSS-Dateien werden anschließend automatisch in CSS übersetzt.

## Übungen

Die Beispiele und Übungen zeigen, wie sich wiederkehrende CSS-Regeln vereinfachen und Stylesheets übersichtlich strukturieren lassen.

Ein Schwerpunkt liegt auf der praktischen Verwendung von Maps, Mixins, Schleifen und Interpolation sowie auf der Umstellung bestehender CSS-Dateien auf eine modulare Sass-Struktur.

Die Beispiele sind teilweise bewusst vereinfacht, um die einzelnen Sass-Techniken verständlich zu demonstrieren.

Die SCSS-Dateien müssen vor der Verwendung im Browser in CSS kompiliert werden. Browser können SCSS-Dateien nicht direkt verarbeiten.

Die Materialien dienen Unterrichts- und Übungszwecken.
